# MNO Sends Confirmation

After processing, the MNO sends a confirmation message back through the payment chain.

## Confirmation Flow

1. M-PESA confirms debit was successful
2. Sends confirmation to Cellulant
3. Cellulant updates transaction status
4. SMS sent to customer with M-PESA message
5. Confirmation propagated to merchant

## M-PESA Confirmation SMS

Customer receives SMS: "M-PESA Confirmed. KSh X.XX sent to [Merchant] on [Date]. New M-PESA balance is KSh XX.XX"
