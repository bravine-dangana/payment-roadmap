# STK Push Sent to Customer

STK (SIM Toolkit) Push is a technology that allows applications to send interactive messages directly to a customer phone.

## How STK Push Works

1. Merchant system sends STK push request to Safaricom API
2. Safaricom sends push notification to customer phone
3. Customer phone displays payment prompt automatically
4. Customer sees amount and merchant name

## STK Push vs USSD

- **STK Push** - Automatic popup on smartphone, better UX
- **USSD** - Manual code entry (*150*00#), works on all phones
