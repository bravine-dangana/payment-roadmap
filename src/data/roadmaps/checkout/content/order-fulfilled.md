# Order Fulfilled

Once payment is confirmed, the merchant fulfills the customer's order.

## Fulfillment Types

- **Digital goods** - Immediate access granted
- **Physical goods** - Shipping initiated
- **Services** - Service activated
- **Airtime/Data** - Delivered instantly
- **Bills** - Bill payment recorded

## Fulfillment Best Practices

- Fulfill only after payment confirmation
- Provide order tracking
- Send confirmation email/SMS to customer
- Handle partial fulfillment scenarios
