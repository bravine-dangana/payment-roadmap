# Cellulant Payment Gateway

Cellulant is a pan-African payment gateway that aggregates multiple payment methods across 35+ African countries.

## Role as Payment Aggregator

- Connects merchants to multiple MNOs via single API
- Handles currency conversion
- Provides unified reporting dashboard
- Manages settlement to merchant bank accounts

## Supported Payment Methods

- M-PESA (Kenya, Tanzania)
- Airtel Money
- MTN MoMo
- Card payments (Visa, Mastercard)
- Bank transfers

## Key Benefits

- Single integration, multiple markets
- Real-time transaction monitoring
- Automated reconciliation
