# MNO (Mobile Network Operator)

The Mobile Network Operator is the telecommunications company that provides the mobile money infrastructure.

## Role in Payment Flow

- Receives payment request from merchant system
- Authenticates customer phone number
- Routes request to appropriate payment processor (e.g. Safaricom for M-PESA)
- Manages STK push delivery

## Key MNOs in East Africa

- **Safaricom** - M-PESA (Kenya)
- **Airtel** - Airtel Money
- **MTN** - MTN MoMo
